# Contributing (lite)

This repository collects **Grok Bot templates** for local businesses. A template is a shareable bot recipe (instructions, skills, routines, and first-party plugins). It is not a hosted app and should not contain secrets.

## Suggestions and issues

- Open an issue (or send a short note to the contact in the README) with: a template name, the pain point, who would use it at least weekly, and how it differs from an existing template here.
- Keep examples **fictional**. Do not paste real customer data, reviews, addresses, staff names, logins, or private file links.
- Do not submit credentials, API tokens, or connector secrets.

## Pull requests

- One focused change per PR (a typo fix, a skill clarification, or a new fictional example).
- Match the existing template layout: `bot-profile.md`, `skills/*/SKILL.md`, `routines.md`, and a `test-run.md` that uses a made-up business.
- Do not add real business names, living people's personal data, or live template-reward claims.

## Public links, pricing, and posts

Changes to public template links, service pricing, or promotional copy need the **repo owner's approval** before they go live. Drafts in this repo are not a live offer until the README says so.

## Language

English or Chinese is fine. If you change user-facing text, consider updating both the English and Chinese sections of the README when the change is user-visible.
