# Grok Bot Templates for Local Businesses

A small collection of [Grok Bot](https://x.ai/bot/guides/templates-for-grok-bot) templates for local shops (cafes, bakeries, salons, restaurants, and retail). Templates are **free to install**. If you want someone to set one up, customize it, or run a weekly draft cycle with you, see [Need it set up for your business?](#need-it-set-up-for-your-business).

---

## What is a Grok Bot template?

A Grok Bot template is a shareable “recipe” copy of a bot: its instructions, skills, routines, and first-party plugins. It does not include secrets, custom MCP servers, or private business data.

You add a template to your own Grok Bot, answer a few setup questions, and then use it as your assistant. Official overview: [Templates for Grok Bot](https://x.ai/bot/guides/templates-for-grok-bot).

This collection focuses on weekly, practical back-office and marketing work for small local businesses — especially shops that need **Chinese and English** at the same time.

## Grok Bot 模版是什么？

模版是一个可分享的 bot「配方」：说明、技能、定时任务和官方插件。不含密码、自定义 MCP，也不含任何一家店的隐私数据。你把它加到自己的 Grok Bot 里，回答几个设置问题，就可以开始用。官方说明：[Templates for Grok Bot](https://x.ai/bot/guides/templates-for-grok-bot)。

本合集侧重小店每周都会用到的后台和营销工作，尤其是需要**中英双语**的店铺。
